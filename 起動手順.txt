==============================
 チンチロアプリ 起動手順
==============================

■ 毎回の起動（これだけでOK）
------------------------------
1. PowerShell（またはターミナル）を開いて、次の2行を実行する

     cd D:\Projects\chinchiro-app
     npm run play

2. 「Tunnel ready.」と QR コードが表示されるまで待つ（数十秒）

3. iPhone で開く（どちらか）
   ・iPhone の標準カメラで QR コードを読み取り、出てきた通知をタップ
   ・Expo Go を開き、ホームの「Development servers」に出る「Chinchiro」をタップ

4. 遊び終わったら、PC 側で Ctrl + C を押してサーバーを止める

※ アプリを開いている間は画面が自動で消えません（閉じれば普段どおり消えます）
※ 他のアプリに切り替えると、iOS が裏の Expo Go を終了させることがあります。
   続けて遊ぶときは Expo Go を前面に出したままにしておくのがおすすめ
   （アクセスガイド：設定 → アクセシビリティ → アクセスガイド を ON にし、
     アプリを開いた状態でサイドボタンを3回押すと、そのアプリから出られなくなる）
※ PC で npm run play を動かしている間だけ遊べます（PC を閉じると開けません）
※ トンネル接続なので、iPhone は PC と別の Wi-Fi やモバイル回線でも OK


■ 前提（最初に一度だけ済ませてあるもの）
------------------------------
・iPhone に Expo Go（App Store・無料）が入っている
・PC と iPhone の Expo Go に、同じ Expo アカウントでログイン済み
    PC 側の確認   : npx expo whoami   （自分のユーザー名が出れば OK）
    PC 側でログイン: npx expo login
    iPhone 側     : Expo Go 右上の人型アイコンからログイン


■ うまくいかないとき
------------------------------
・「You need to be signed in to Expo Go and Expo CLI」と出る
    → PC と iPhone のどちらか（または両方）がログインしていない。上の「前提」を確認。
      ターミナルの URL に「anonymous」が入っていたら PC 側が未ログイン。

・「SDK バージョンが合わない」などと出て開けない
    → App Store で Expo Go を最新版に更新する（このアプリは SDK 57）

・トンネルがつながらない／途中で切れる
    → Ctrl + C で止めて、もう一度 npm run play

・様子がおかしい、古い状態のまま表示される
    → キャッシュを消して起動し直す
         npm run play -- -c
      その後、iPhone の Expo Go を完全に終了（アプリ切り替え画面で上にスワイプ）してから開き直す

・ターミナルで r を押すと「No apps connected」と出る
    → npm run play のモードでは r での再読み込みは効かない。
      iPhone の Expo Go を完全に終了して、開き直せば最新の状態で読み込まれる（サーバーはそのままでよい）

・音が鳴らない
    → iPhone の消音スイッチ（マナーモード）が ON だと鳴らない仕様。振動は出る。

・振動しない
    → iPhone の「設定 → サウンドと触覚 → システムの触覚」が ON か確認
